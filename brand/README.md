# Proofhaus brand

The mark is a roof over the letter H: a house for "haus", and a proof house, the institution that tests
things to destruction and stamps what survives. The roof is also a caret, a nod to the terminal the product
lives in.

## Files

| file | use |
|------|-----|
| `proofhaus-logo-dark.svg` | primary lockup, for dark surfaces |
| `proofhaus-logo-light.svg` | primary lockup, for light surfaces |
| `proofhaus-logo-black.svg`, `proofhaus-logo-white.svg` | single colour, for print and mono contexts |
| `proofhaus-stacked-dark.svg`, `proofhaus-stacked-light.svg` | stacked lockup for square spaces |
| `proofhaus-mark*.svg` | the mark alone |
| `proofhaus-avatar.png`, `proofhaus-avatar-green.png` | 1024px tiles for profiles |
| `proofhaus-logo-square.png` | 1024px stacked lockup on a dark tile |
| `proofhaus-icon-512.png` | app and favicon tile |

## Colour

| name | hex | where |
|------|-----|-------|
| phosphor green | `#2ff5a0` | mark and accents on dark |
| deep green | `#0a7d55` | mark and accents on light |
| ink | `#06080a` | dark surfaces |
| text | `#e8f0ec` | wordmark on dark |

## Usage

- Clear space around the mark equals the width of one pillar of the H.
- Smallest sizes: mark 16px, lockup 96px wide.
- Use the dark lockup on dark surfaces and the light lockup on light ones. Do not recolour, stretch, rotate or
  add effects.
- The wordmark is set in Archivo SemiBold (SIL Open Font License) and converted to outlines, so no font
  installation is needed.
